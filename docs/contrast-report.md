## How to maintain this report

This report is the source of truth for whether a token combination is
safe to use as text. **Any time** the following change, regenerate:

1. New ink/surface token added to `colors_light.dart` or `colors_dark.dart`
2. Alpha value modified on any composited ink (e.g. `inkFaint @ 0.60`)
3. Hex value changed on a surface or ink base
4. Yellow / phase / status colors retuned

To regenerate, edit the token tables at the top of `/tmp/contrast.py`
to match the new values, then:

```bash
python3 /tmp/contrast.py
```

It rewrites this file in place. Commit both the token change AND the
new report in the same commit — reviewers should be able to verify the
contrast claims without rerunning the script.

If the script is gone (it lives in /tmp), it's reproduced inline at the
top of `Phase 1` of the master UI system PR description.

## Routing rules (enforced via doc comments on the tokens)

| Use case                              | Light token      | Dark token       |
|---------------------------------------|------------------|------------------|
| Primary body text                      | `ink`            | `ink`            |
| Eyebrow / caption / secondary text     | `inkSoft`        | `inkSoft`        |
| Hint / metadata under a value          | `inkSoft`        | `inkSoft`        |

Eyebrows routed through `inkSoft` by default in `PlanEyebrow`. Override
via the `color:` parameter only when the design genuinely calls for a
yellow accent (`yellow`) or a status color (`attention`, `live`).
